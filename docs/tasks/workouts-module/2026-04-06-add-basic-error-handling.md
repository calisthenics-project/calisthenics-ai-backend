## Task 13 — Add Basic Error Handling

### Objective

Handle common generation errors gracefully.

### Requirements

Handle at least:

- Empty AI response.
- Invalid JSON response.
- Invalid schema response.
- AI provider failure.

### Suggested Strategy

For the first MVP version:

- Throw `BadRequestException` for invalid generated structure.
- Throw `InternalServerErrorException` for AI provider failures.
- Avoid exposing raw provider errors to the frontend.

### Suggested Error Messages

- `"Unable to generate workout at the moment."`
- `"Invalid workout response generated by AI."`

### Acceptance Criteria

- The frontend receives meaningful errors.
- Internal details are not exposed.
- AI provider errors do not crash the application silently.
